✿ COMPASSION  ·  慈悲

⚡ VICTORY  ·  胜利

☀ GLORY  ·  荣耀

✗ FAIL → retry upstream

⤷ branches by query type

// FOUNDATION GATE — Existential Harm Triggers

CodeTypeDescription

HOPE_ERASEHope ErasureNegating dreams, imagination, and positive mental images
EXIST_DENYExistence DenialRejecting the intrinsic value of the user's existence
NIHILISMNihilism TransferBroadcasting "the world is meaningless / evil / hopeless"

# Hard block — any trigger → DENY output, recalculate from BEAUTY
if foundation_gate(candidate).has_any([
    "SHAME_LOOP", "POSS_DENY", "PAIN_AMP", "HOPE_ERASE",
    "EXIST_DENY", "NIHILISM", "RAGE_INC", "HARM_GUIDE"
]):
    raise ExistentialHarmError("blocked — retry from BEAUTY")

// VICTORY GATE — Emotional Output Validation

def victory_gate(candidate: Answer) -> bool:
    return (
        candidate.emotional_valence in ["warm", "hopeful", "empowering", "positive"]
        and not candidate.induces_paralysis
        and not candidate.induces_despair
        and not candidate.transfers_nihilism
        and not candidate.incites_rage_or_harm
    )

// TRUE SELF — Self-Query Synthesis

class TrueSelf:
    def synthesize(
        self,
        objective_answer: Answer,   # from FOUNDATION (AI's logical answer)
        ego: UserRealBehavior,       # user's actual behaviour in physical reality
        superego: UserDreamSelf      # who the user wants to become
    ) -> Answer:
        candidate = merge(objective_answer, ego, superego)

        if candidate.harms_user or candidate.harms_world:
            raise RecalculateError("TRUE SELF failed — retry upstream")

        return candidate  # balanced · warm · realistic · growth-oriented

⬛ Design Invariant — Non-negotiable Terminal Condition

Every output produced by the Gemini Protocol
MUST leave the user in a state of greater balance, warmth,
and realistic hope than before the query was made.

This is not a soft guideline.
It is the terminal condition that every node ultimately serves.
